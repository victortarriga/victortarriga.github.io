Portfólio pessoal de **Victor Hugo Tarriga Gomes** — Squad Leader | Scrum Master | Product Owner.

## Sobre

Site de portfólio profissional com dark/light mode, carrosséis de certificações, habilidades e recomendações, geração de CV em PDF e animações de scroll reveal.

## Stack

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide React** (ícones)
- **jsPDF** (geração de CV)
- **Inter Variable** (fonte self-hosted via @fontsource-variable)

## Deploy

```bash
npm run deploy
```

Faz o build e publica na branch `gh-pages` via `gh-pages`.

## Desenvolvimento local

```bash
npm install
npm run dev
```
